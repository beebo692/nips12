# Project Page

Anonymized project page for the paper *Not All Features Are Created Equal: A Mechanistic Study of Vision-Language-Action Models* (currently under double-blind review).

## Local Preview

Open `index.html` in a browser, or run a local server:

```bash
python3 serve.py 9999
# then visit http://localhost:9999
```

## Structure

```
.
├── index.html          # Main project page (single page, all sections)
├── serve.py            # Optional local preview server
└── static/
    ├── css/            # Bulma + custom styles
    ├── js/             # FontAwesome
    ├── images/         # Figures and screenshots
    └── videos/         # Hero background
```
